# Stampz MVP product scope

## In scope (Phases 0–1)

- Auth (email/password) for Customer, Merchant Owner, Staff, Super Admin
- Merchant onboarding + loyalty program creation
- Customer QR + merchant scan → stamp → reward unlock → redeem
- Merchant dashboard KPIs
- Public business profile by slug

## Phase 2+

- Staff invites + RBAC
- Campaigns
- Gallery / menu / links / branches
- Offline QR sync
- Notifications
- Stripe + Apple/Google IAP entitlements
- Admin merchant/billing tools
- i18n (en/ne), discovery map search, GDPR export/delete

## Mobile

React Native (Expo) — Android + iOS (not Flutter).
