# Internationalization (i18next)

Stamp Perk web uses **i18next** + **react-i18next** with locale JSON files.

## Locales

| Code | Language |
|------|----------|
| `en` | English |
| `ne` | Nepali |
| `hi` | Hindi |
| `es` | Spanish |
| `fr` | French |
| `de` | German |
| `zh` | Chinese |

Files live in `apps/web/src/locales/{code}/common.json`.

## Usage

```tsx
import { useTranslation } from 'react-i18next';

const { t, i18n } = useTranslation('common');
t('heroBody');
i18n.changeLanguage('ne');
```

Language is detected from `localStorage` (`stampperk_i18nextLng`) then the browser, and can be changed from the Display control.

## Add a language

1. Create `src/locales/{code}/common.json` (copy from `en`)
2. Import it in `src/i18n/index.ts`
3. Add `{ code, label, native }` to `SUPPORTED_LOCALES`
